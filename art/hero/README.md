# Герой в Aseprite

Файл `hero.aseprite`: здесь рисуется герой. Сейчас в нём лежит графика из
Pyxel-версии, увеличенная ×2. Её можно перерисовать поверх или стереть и нарисовать заново.
Враги и жители собраны из своих листов (`assets/sprites/characters`), поэтому
изменения героя их не затронут.

## Как это попадает в игру

1. Открыть `art/hero/hero.aseprite`, рисовать, сохранить (Ctrl+S).
2. Из папки проекта запустить:
   ```
   python tools/import_hero.py
   ```
   Импорт соберёт листы `assets/sprites/hero/*.png` и `hero.json`. Если что-то
   не так (нет слоя, метки или точки привязки), он остановится и напишет, что
   исправить.
3. Переключиться в Godot, он подхватит новые PNG сам, и нажать F5.

Если шаблон испорчен и нужно начать заново, запустите `python tools/hero_template.py --force`.
Команда перезапишет `hero.aseprite` текущими листами из игры, поэтому сначала сделайте копию.

## Холст

- 48x64 пикселя на кадр, герой смотрит **вправо** (влево игра отражает сама).
- Ноги стоят на **нижнем ряду** холста, герой по центру по горизонтали.
- Слой `_guide` (опорный, в игру не идёт) показывает хитбокс 20x44 (зелёный)
  и землю (оранжевая линия).
- Холст можно увеличить (Sprite → Canvas Size), чтобы добавить места для замаха
  или плаща. Расширяйте поровну влево и вправо, а вверх — сколько нужно; низ
  не двигать. Игра прочитает новый размер сама.

## Слои

| Слой | Что это | Когда виден в игре |
|---|---|---|
| `legs` | ноги, штаны, обувь | всегда |
| `torso_plain` | голый торс (без доспеха) | ничего не надето |
| `torso_shirt` | рубаха | надета рубаха (стартовая) |
| `torso_leather` | кожаный доспех | надет кожаный доспех |
| `torso_mail` | кольчуга | надета кольчуга |
| `head` | голова, лицо, волосы | всегда |
| `helmet_cap` | шапка | надета шапка |
| `helmet_shishak` | шишак | надет шишак |
| `anchors` | точки привязки (см. ниже) | не рисуется |
| `_weapon` | меч там, где его покажет игра (опорный) | не рисуется |

Игра накладывает слои снизу вверх: ноги → один торс → голова → один шлем → оружие.
Руки рисуются в слоях торса: у каждого доспеха свои рукава.
Пока рисуете один торс, остальные скройте (глазик): в игре виден только один из них.

- **Не переименовывайте** слои из таблицы.
- Свои слои (набросок, подложка) называйте с `_` в начале, тогда игра их пропустит.
- Можно разбить лист на группу: например, группа `legs` со слоями «контур» и «заливка».
  Игра склеит видимые слои группы.
- Цвета любые. Палитра Pyxel-версии лежит в файле для удобства, но вы ей не ограничены.
- Оружие и щит в слои **не рисуются**: игра добавляет их сама по точкам привязки.
  Слой `_weapon` только показывает, где окажется меч.

## Метки (теги) — анимации

Названия меток менять нельзя. Число кадров в метке менять можно: игра растянет
анимацию на то же время. Длительности кадров в Aseprite нужны только для
просмотра, темп в игре задаёт код.

| Метка | Сейчас кадров | Как играет |
|---|---|---|
| `idle` | 4 | стоит; кадр раз в 0,25 с по кругу |
| `run` | 6 | бег; кадр раз в 0,083 с по кругу |
| `jump` / `fall` | 1 / 1 | взлёт / падение |
| `roll` | 6 | перекат, растянут на весь перекат (~0,37 с) |
| `block` | 1 | щит / блок |
| `attack`, `attack2` | 4, 4 | удары серии (чередуются), растянуты на удар; удар — в середине |
| `heavy` | 4 | **1-й кадр** — замах (держим кнопку), остальные — сам удар |
| `plunge` | 1 | удар сверху в падении |
| `cast` | 2 | чары; кадр раз в 0,1 с |
| `hurt` | 1 | получил удар / оглушён |
| `death` | 4 | гибель, растянута на ~0,67 с, последний кадр остаётся |

## Точки привязки (слой `anchors`)

В **каждом** кадре на слое `anchors` должно стоять по одному пикселю трёх цветов:

| Цвет | Точка | Зачем |
|---|---|---|
| красный `#FF0000` | `hand` — кисть | сюда встаёт рукоять оружия и щит в блоке |
| синий `#0000FF` | `back` — спина | щит за спиной |
| зелёный `#00FF00` | `head` — голова | звёздочки оглушения |

Угол оружия в кадре записан в свойствах ячейки (cel) слоя `anchors`. Двойной
щелчок по ячейке → Cel Properties → User Data. Там текст `weapon=30`:
0 — клинок вверх, положительный угол — по часовой стрелке, 90 — вперёд.
`weapon=-` прячет оружие (перекат, чары).

Перерисовали руку — передвиньте красную точку и поправьте угол. Слой `_weapon`
после этого будет показывать меч по-старому: это только подсказка, проверяйте в игре.
